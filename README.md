## Featured Projects

### Employee Request Management

A Power Platform solution designed to allow employees to submit, track, and manage requests through a centralized application.

**Technologies Used**

- Power Apps
- Power Automate
- Microsoft Teams

**Key Features**

- Request submission and tracking
- Manager approval workflows
- Automated notifications
- Dynamic filtering and searching
- Role-based user experience
- Form validation

### Architecture

The solution uses Power Apps as the user interface, SharePoint for application data, and Power Automate for workflow automation and notifications.

```text
Power Apps
    ↓
SharePoint
    ↓
Power Automate
    ↓
Teams / Outlook
```

### Power Fx Example

```powerfx
Filter(
    Requests,
    Status = ddStatus.Selected.Value
)
```

This formula dynamically filters requests based on the status selected by the user.
